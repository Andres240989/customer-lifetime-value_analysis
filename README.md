# Customer Lifetime Value (CLV) Analytics Dashboard

## 📌 Project Overview

This project develops an interactive **Customer Lifetime Value (CLV) analytics dashboard** designed to help businesses understand customer value, evaluate acquisition channels, segment customers, and identify customers that may require retention actions.

The project combines **Python-based data analysis, customer segmentation, business KPIs, and an interactive Streamlit dashboard** to transform customer-level data into actionable business insights.

The dashboard is designed as an MVP that could serve as a foundation for a more advanced commercial analytics solution.

---

## 🎯 Business Problem

Companies can acquire customers through different channels, but not all customers generate the same economic value.

A business needs to understand:

* Which acquisition channels generate the most revenue?
* Which customers represent high, medium, or low value?
* How much net value is generated by each customer?
* Which channels contain a high concentration of low-value customers?
* Which customers could require retention or commercial actions?

Without customer-level analysis, businesses may focus only on total revenue and overlook differences in **customer profitability and value**.

This project addresses this problem by combining customer segmentation with an interactive dashboard.

---

## 🎯 Project Objectives

The main objectives are:

* Analyze customer revenue and acquisition costs.
* Calculate customer net value.
* Compare customer performance across acquisition channels.
* Segment customers according to their economic value.
* Build business KPIs that dynamically respond to dashboard filters.
* Identify low-value customers that could require retention strategies.
* Create an interactive dashboard that allows users to explore the data.

---

## 📊 Dataset

The dataset contains customer acquisition information with the following main variables:

| Variable          | Description                                     |
| ----------------- | ----------------------------------------------- |
| `customer_id`     | Unique customer identifier                      |
| `channel`         | Customer acquisition channel                    |
| `cost`            | Acquisition cost                                |
| `conversion_rate` | Conversion rate associated with the acquisition |
| `revenue`         | Revenue generated by the customer               |
| `net_value`       | Customer revenue minus acquisition cost         |

The acquisition channels include:

* Email Marketing
* Referral
* Paid Advertising
* Social Media

## 🔄 Data Processing

The project follows a data preparation and analysis workflow:

```text
Raw Customer Data
        ↓
Data Cleaning
        ↓
Feature Engineering
        ↓
Customer Value Scoring
        ↓
Customer Segmentation
        ↓
Interactive Dashboard
```

### Feature Engineering

A key variable created during the analysis is:

```text
Net Value = Revenue - Cost
```

This provides an additional perspective beyond revenue by considering the cost required to acquire each customer.

---

## 👥 Customer Segmentation

Customers were segmented according to their economic value.

The project uses a **customer value scoring approach** based on:

* Revenue
* Net Value
* Acquisition Cost

The resulting segments are:

* `high_value`
* `medium_value`
* `low_value`

A customer value score was also created to support the segmentation process.

## 📈 Interactive Dashboard

The dashboard was developed using **Streamlit** and provides interactive business analysis.

### Main KPIs

The dashboard includes:

* **Total Revenue**
* **Total Customers**
* **Total Net Value**
* **Average Conversion Rate**

## 🚨 Customer Retention Alert

One of the main analytical components of the dashboard is the **Low Value Customer Risk Analysis**.

The dashboard identifies customers classified as `low_value` and allows the user to examine their individual information.

The analysis can display:

**| Customer    | Revenue | Channel | Cost |**

This provides a starting point for developing future **customer retention and commercial action strategies**.

The idea is to move from descriptive analytics toward an actionable workflow:

```text
Customer Segmentation
        ↓
Identify Low-Value Customers
        ↓
Evaluate Customer Metrics
        ↓
Identify Customers Requiring Attention
        ↓
Retention Strategy
```

## 📝 Business Recommendations

Based on the customer segmentation and channel-level analysis, the following recommendations can be considered to improve customer value and commercial decision-making.

1. Prioritize High-Value Customers

Customers classified as high_value should receive greater commercial attention because they represent the customers with the strongest economic contribution.

Recommended actions include:

Develop customer retention strategies.
Identify opportunities for cross-selling and upselling.
Prioritize personalized commercial communication.
Monitor changes in revenue and net value over time.

The objective is to protect the customers that generate the greatest economic value for the business.

2. Develop Targeted Strategies for Low-Value Customers

Low-value customers should not necessarily be treated as lost customers. Instead, they can be analyzed to determine whether their value can be increased.

Possible actions include:

Analyze their acquisition channel.
Evaluate acquisition cost versus generated revenue.
Identify opportunities to increase purchase frequency or revenue.
Develop targeted commercial campaigns.
Monitor their evolution after a commercial intervention.
